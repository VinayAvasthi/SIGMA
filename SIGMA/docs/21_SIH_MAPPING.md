# SIH Mapping

## Problem-to-Solution Traceability

| Problem/Need | SIGMA Response |
|---|---|
| Manual signal analysis | Automated processing pipeline |
| `.IQ` recordings | IQ ingestion and complex-sample analysis |
| `.WAV` recordings | WAV ingestion and time/frequency analysis |
| Signal identification | Candidate signal detection |
| Parameter extraction | Parameter Extraction Engine |
| Large datasets | Chunked/background processing |
| Inconsistent results | Standardized result schema and provenance |
| Visual analysis | Spectrum/spectrogram/waterfall dashboard |
| Intelligent characterization | Optional AI/ML inference |
| Downstream use | JSON/API/CSV outputs |
| Documentation | Architecture, flow, test, and deployment docs |

## Jury Demonstration Flow

1. Upload sample recording.
2. Show metadata detection.
3. Start analysis.
4. Show processing stages.
5. Show spectrum and spectrogram.
6. Highlight detected signals.
7. Show extracted parameters.
8. Show ML result if a validated model is connected.
9. Export JSON.
10. Generate the human-readable report.

The demo should use representative or synthetic data unless the team is authorized to use operational recordings.
