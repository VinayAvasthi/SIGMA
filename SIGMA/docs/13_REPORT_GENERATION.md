# Report Generation

## Report Contents

1. Analysis identifier.
2. Source file metadata.
3. Input checksum.
4. Processing configuration.
5. Signal detections.
6. Extracted parameters.
7. AI/ML predictions.
8. Confidence/quality indicators.
9. Spectrum/spectrogram/waterfall figures.
10. Processing software/model versions.
11. Limitations and unavailable parameters.

## Output Formats

Recommended:

- PDF for human review.
- JSON for machine consumption.
- CSV for tabular analysis.

The report generator must use the same stored result object as the API so that the displayed values remain consistent.
