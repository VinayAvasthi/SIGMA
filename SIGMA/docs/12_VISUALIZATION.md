# Visualization

## Required Views

### Time Domain
Shows amplitude versus time.

### Spectrum
Shows power/magnitude versus frequency.

### Spectrogram
Shows how spectral content changes over time.

### Waterfall
Provides a scrolling or stacked representation of spectral activity.

### I/Q Plot
Shows complex-sample trajectory.

### Constellation
Applicable to signals for which constellation interpretation is meaningful.

## Interaction

Users should be able to:

- Zoom.
- Pan.
- Select a time/frequency region.
- Inspect a detected segment.
- Compare extracted values.
- Export plots.

Visuals should show units, scale, sampling assumptions, and relevant metadata.
