# Parameter Extraction

## Parameter Categories

### Frequency
- Peak frequency.
- Center frequency.
- Lower/upper frequency bounds.

### Bandwidth
- Estimated occupied bandwidth.
- Threshold-defined bandwidth.

### Power
- Average power.
- Peak power.
- Relative power where absolute calibration is unavailable.

### Quality
- Noise estimate.
- SNR.
- Detection confidence/quality metrics.

### Time
- Start time.
- End time.
- Duration.

### Spectral Features
- Spectral centroid.
- Spectral spread.
- Peak count.
- Spectral shape descriptors.

### Modulation Features
Only where the signal and implementation support meaningful extraction.

## Provenance

Each extracted value should retain:

- Method.
- Algorithm version.
- Configuration.
- Units.
- Confidence/quality indicator.
- Source segment.
